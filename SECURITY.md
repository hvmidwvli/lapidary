# Security

Lapidary is one markdown file (`skills/lapidary/SKILL.md`). It has no scripts, hooks or network calls, and it asks the AI to do nothing beyond writing a prompt and, in default mode, carrying that prompt out with the permissions you already gave your AI tool.

Skills are instructions your AI follows, so **read `SKILL.md` before you install it**, here and anywhere else. Install a tagged release, not the moving branch.

## Reporting a problem

Use this repository's **Security** tab → **Report a vulnerability** (private). If that is not shown, open an issue that says only "security contact needed", with no details, and a private channel will be arranged.
